# Gava Originator Digital Tech — Digital Flyer

A responsive, single-page promotional flyer for Gava Originator Digital Tech.

## View the flyer
Once GitHub Pages is enabled, visit: https://kabelogopane.github.io/Gava-Digital-Flyer/

## Publish with GitHub Pages
1. Open the repository **Settings**.
2. Select **Pages** in the left menu.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/ (root)**, then save.
5. Wait for GitHub Pages to publish the site.

The flyer links to the main Gava website enquiry section. Business contact details can be added when confirmed.
